# 実装時の検証記録

確認日：2026-11-08。対象はこのリポジトリの初期実装です。配布後の依存更新や各自の改造後は、必要な項目を再確認してください。

## 確認環境

- Linux、ホストNode.js 24.19.0、npm 11.17.0。
- Docker 29.9.3、`node:24-bookworm-slim`（検証時Node.js 24.21.0）。
- Google Chrome 157、1440px幅と390px幅。
- 既存の `.env` の内容を上書きせず、テストにはモックと別の一時DBを使用。

## 成功した確認

| 対象 | 確認内容 |
| --- | --- |
| 初期セットアップ | `npm install`、`npm run setup:local`。既存 `.env` を保持 |
| 開発起動 | `npm run dev` でReactとHonoを同時起動、5173番からアクセス |
| 型とビルド | `npm run check`：両ワークスペースの型チェック、Viteビルド、11件の自動テスト |
| 入力とCRUD | 作成・読み込み・更新・削除、日本語検索、複合フィルタ、入力不正・不明ID・巨大データの拒否 |
| DB | ファイルDBの再オープン、カードと分析の保持、削除後のサンプル再投入防止 |
| AI | モック分析と保存、SDK経由のResponses API送信形式・応答読み取りを偽fetchで確認 |
| AI障害 | 未設定・無効・API失敗でもCRUDが利用可能。既存の分析結果を保持 |
| 制限と競合 | 失敗を含む日次上限、再起動後の制限保持、UTC日付の切り替え、二重分析と途中編集の扱い |
| ブラウザー | 作成→検索→分析→再読み込み→編集→削除。グリッド／リスト、検索0件、条件クリア、Escapeで閉じる |
| 小さい画面 | 390pxで横はみ出しなし、フォーム表示と削除を操作可能 |
| ブラウザーエラー | 一連の操作でJavaScript実行エラーなし |
| Compose | installサービスで `npm ci`、APIのhealthcheck、frontend起動、同じブラウザー操作をコンテナ版でも確認 |
| ビルド済み配信 | APIサーバーからHTML・JavaScriptを200で配信、不明APIはJSON 404 |
| 秘密情報の分離 | `.env`・`.env.compose`・DBがGit管理対象外。フロントエンドの成果物にAPIキー設定やSDKを含めない構成 |
| 依存監査 | Hono Nodeアダプターを修正版に更新後、`npm audit` は脆弱性0件 |
| 整合性 | Compose構文、`git diff --check`、教材内の相対リンク |
