# AI Webアプリ開発ワークショップ 要件定義

## 1. 概要

初心者を対象に、生成AI（Codex）を活用したWebアプリ開発を体験するワークショップを実施する。

全4回（各2時間、計8時間）で、開発環境の構築からフロントエンド・バックエンド・データベース・生成AI APIの活用までを学ぶ。

参加者は共通のサンプルアプリを改造し、各自のオリジナルアプリを完成させる。

## 2. 技術スタック

| 項目 | 技術 |
|---|---|
| フロントエンド | React + Vite + TypeScript |
| バックエンド | Hono + Node.js |
| データベース | SQLite |
| 生成AI | OpenAI API（Responses API） |
| AI開発支援 | ChatGPT / Codex |
| 開発環境 | VS Code |
| バージョン管理 | Git / GitHub |

開発・実行はローカル環境で完結させ、デプロイは行わない。

OpenAI APIは講座当日限定で利用可能な認証情報を提供する。

## 3. サンプルアプリの要件

### アプリ概要

**AIアイデアボード**

アイデアやメモをカード形式で登録・管理できるWebアプリ。

参加者が用途に応じてUI・データ構造・AI機能を変更し、タスク管理、読書管理、旅行計画などのアプリに発展させられる設計とする。

### 基本機能

- カードの一覧表示・新規作成・編集・削除（CRUD）
- カテゴリ・ステータスによる分類
- キーワード検索・フィルタリング
- SQLiteによるデータ永続化
- ReactからHono APIを経由したデータ操作
- OpenAI APIを使用したアイデアの分析・提案生成
- AIによる生成結果の表示・保存

### 技術要件

- `npm install`、`npm run dev`で起動できること
- ReactとHonoをローカルで同時起動できること
- SQLiteの初期化を自動化すること
- OpenAI APIキーはバックエンド側の環境変数で管理すること
- APIキーが無効でもAI以外の基本機能が利用できること
- GitHubでソースコードを管理できること
- 初心者がCodexで改造しやすいシンプルな構成とすること

## 4. カリキュラム

| 回 | テーマ | 内容 |
|---|---|---|
| 第1回 | 環境構築・AI開発入門 | VS Code、Git、GitHub、Node.js、Codexの導入。サンプルアプリの起動・簡単な改造 |
| 第2回 | フロントエンド開発 | Reactの基本、AIによるUI・コンポーネントの変更 |
| 第3回 | バックエンド・DB開発 | HonoによるAPI開発、SQLiteの操作、CRUD・データ構造の変更 |
| 第4回 | AI機能の実装 | OpenAI API連携、プロンプト設計、AI機能追加、成果共有 |

各回で共通課題と自由改造を実施し、オリジナルアプリ制作のための独立した回は設けない。

## 5. 教材・運営要件

講師側で以下を準備する。

- 動作確認済みのサンプルアプリ一式
- 環境構築マニュアル（Windows / macOS）
- 各回のハンズオン資料
- Codexへの指示例・プロンプト集
- トラブルシューティング資料
- 講座用のOpenAI API利用環境と利用制限

## 6. 最終到達目標

参加者が以下を実現できること。

1. ローカル環境でWebアプリを起動できる。
2. Codexに自然言語で指示してアプリを改造できる。
3. React・Hono・SQLiteの基本的な役割を理解できる。
4. OpenAI APIを利用したAI機能を実装できる。
5. サンプルアプリを自分の用途に合わせて改造し、GitHubに成果物を保存できる。

**最終成果物：React + Hono + SQLite + OpenAI APIを活用した、参加者独自のローカルWebアプリ。**
