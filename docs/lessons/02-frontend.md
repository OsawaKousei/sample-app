## 仕組みとコードを読む

HTMLは構造、CSSは見た目、JavaScriptは操作を担当します。このアプリではReactで画面を組み立て、TypeScriptでデータの型を表します。

- `App.tsx`：TODOのstate、保存処理、テーマ別・優先度別のグループ化。
- `TodoForm.tsx`：入力と送信。
- `TodoCard.tsx`：一つのTODOの表示。
- `AiPlanner.tsx`：AIに伝える目標の入力。
- `styles.css`：配色・余白・画面幅に応じた配置。

Codexに「props・state・イベントを、このアプリの具体例で説明してください」と依頼します。`todos` が変わると一覧が変わること、カードがpropsでデータと関数を受け取ることをコードで確認します。

## 共通課題：ダッシュボードの見た目を変更する

配色、TODOカード、優先度、テーマ別・優先度別表示を改造します。

```text
AI TODOプランナーのダッシュボードを青を基調とした配色に変えてください。
TodoCard.tsxとstyles.cssを中心に、カードの余白と見出しを読みやすくしてください。
優先度は文字を残し、高いものほど目に入りやすい表示にしてください。
テーマ別・優先度別のグループ見出しも整理してください。
登録・編集・削除・ステータス変更は引き続き使えるようにし、
変更後にnpm run checkを実行してください。
```

一度に大きく変えすぎず、変更結果をブラウザーで見てから追加修正を依頼します。色だけで状態を区別しないことも確認します。

## 自由改造と確認

旅行、学習、家事など自分の用途を一つ選び、見出し、説明文、カードの雰囲気を合わせます。

- 画面が広いときと390px幅で、読みやすく操作できる。
- Tabキーで入力・ボタン・ステータス選択へ移動できる。
- 未入力、保存中、AI生成中、エラーの表示が分かる。
- 表示を変えても、編集と再読み込み後の保存が動く。

`git diff` で差分を確認し、変更したファイルをコミット・pushします。どんな依頼で何が変わったかを共有します。
