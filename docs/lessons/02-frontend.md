## 読んでみる

- `App.tsx` の `useState`：検索語やカテゴリなど、画面が覚えている状態。
- `visible`：選択した条件に一致するカード。
- `visible.map(...)`：カード1枚ずつの表示。
- `CardDialog.tsx` のprops：親から渡されるカード・通知先。
- `styles.css` の `@media`：画面幅に合わせた表示。

Codexに「`query` を入力してから画面が変わるまで、どのコードが動くか初心者向けに説明して」と依頼し、自分でも該当箇所をたどります。

## 共通課題：IdeaCardコンポーネントに分ける

```text
App.tsxのカード1枚を表示するarticleを、
frontend/app/src/IdeaCard.tsx に切り出してください。
cardとonOpenをpropsで受け取り、今の見た目・検索・編集の動作を保ってください。
カテゴリとステータスに必要な定数の置き場所も整理してください。
変更後にnpm run typecheckを実行し、propsの役割を説明してください。
```

一度に機能を増やさず、切り出し前後で同じカードが表示されることを確認します。
