# 第1回：環境構築・AI開発入門（120分）

ゴール：自分のPCでボードを起動し、Codexを使って小さな改造を1つ行い、GitHubに記録する。

準備：[環境構築](../setup.md)のインストールを済ませ、講師のリポジトリを取得します。APIキーは不要です。

## 進め方

| 時間 | 内容 |
| --- | --- |
| 0〜15分 | 完成例と全4回の流れ。自分が作ってみたいアプリを一言で書く |
| 15〜45分 | ツール・バージョン確認、取得、インストール、起動 |
| 45〜65分 | カードを作成・編集・削除し、練習用AI応答を見る |
| 65〜75分 | 休憩と質問 |
| 75〜100分 | 共通課題：見出しと説明文をCodexで変更 |
| 100〜115分 | 自由改造・動作確認・Gitの記録 |
| 115〜120分 | 隣の人に変更箇所を紹介、振り返り |

## ハンズオン1：起動してデータを残す

```sh
npm install
npm run setup:local
npm run dev
```

1. http://127.0.0.1:5173 でボードを開く。
2. 「アイデアを追加」から、自分の作りたいアプリを記録する。
3. カテゴリとステータスを変えて保存し、検索して探す。
4. ページを再読み込みしてもカードが残ることを確認する。
5. カードを開き、「AIで分析して保存」を試す。練習用の固定応答で、実AIへの通信はしていないことを確認する。

## 共通課題：自分のボードに名前を付ける

VS Codeで `frontend/app/src/App.tsx` を開き、Codexに伝えます。

```text
このリポジトリのREADME.mdとdocs/spec.mdを読んでください。
App.tsxのメイン見出しを「わたしの読書ボード」に変更し、
説明文を「気になる本と、読んだあとの気づきを集めよう。」にしてください。
変更箇所と、ブラウザーでの確認方法を説明してください。
```

差分を読んで、意図した文だけが変わったか、ブラウザーに反映されたかを確認します。AIの説明だけで判断せず、実際に操作します。

## 自由改造

- 見出しを旅行・タスク・趣味など自分の用途に変える。
- ボタンの文言を分かりやすくする。
- `styles.css` の `.primary-button` の色を変える。

## 記録と完了条件

```sh
git diff
git add frontend/app/src/App.tsx
git commit -m "Customize my board title"
git push
```

- 自分のカードが再読み込み後も残る。
- 見出しの変更を説明できる。
- GitHubでコミットを確認できる。

振り返り：「AIに伝わりやすかった指示」と「次に変えたいこと」を1つずつ書きます。起動できない場合は[トラブルシューティング](../troubleshooting.md)を確認します。
