# 第1回：環境構築・Codex入門（120分）

テーマ：AIを使ったWebアプリ開発を始めよう。

ゴール：開発環境を用意し、AI TODOプランナーを起動して、Codexの基本的な使い方とアプリの全体構造を理解します。

## 準備と対象範囲

[環境構築](../setup.md) に沿って、VS Code・Node.js・Git・GitHub・Codexを準備します。Windows / macOSへNode.jsを直接インストールし、Dockerは使いません。

講座ではローカルで動くアプリを作ります。公開・インフラ構築・本番運用は対象外です。APIキーはパスワードと同様に扱い、ソースコード・React・GitHubへ含めません。AIが作ったコードも自分で動作を確認します。

## Codexを使ってみる

まず、変更せず説明してもらいます。

```text
README.mdとdocs/architecture.mdを読み、このアプリを起動する手順と、
画面・API・DB・AIがそれぞれ担当する役割を初心者向けに説明してください。
この段階ではファイルを変更しないでください。
```

指示 → 説明・変更案 → 差分確認 → 動作確認 → 追加修正、という流れを確認します。目的と完成条件を具体的に書くこと、APIキーをチャットに貼り付ける必要がないことを学びます。

## 起動して操作する

リポジトリを取得し、`.env.example` を `.env` にコピーします。

```sh
npm install
npm run dev
```

http://127.0.0.1:5173 を開きます。

1. 「週末の旅行の準備」などのTODOを手動登録する。
2. 編集から説明・テーマ・優先度を変える。
3. AIへ「週末に日帰り旅行をしたい」と伝えてTODOを生成する。
4. テーマ別・優先度別の表示を切り替える。
5. 未着手 → 進行中 → 完了に変更する。
6. ページを再読み込みして保存を確認し、不要なTODOを削除する。

キー未設定の場合はサンプルが生成されます。実APIへ接続する場合は `.env` を編集してサーバーを再起動します。

## 全体構造とGit

`frontend/app/src/App.tsx`、`api/app/src/app.ts`、`api/app/src/database.ts`、`api/app/src/ai.ts` を開き、担当を確認します。Reactの画面からHTTPを送り、APIがDBやAIを呼び出す流れを図にします。

`git status` と `git diff` で作業状態を確認します。講師の案内に沿って自分のGitHubリポジトリを用意し、以降の改造をコミット・pushできるようにします。`.env` と `.local/` はGitの対象外です。

## 完了条件

- 自分のPCで起動し、手動操作とAI生成を試せた。
- Codexにコードを説明してもらい、役割を探せた。
- APIキーの扱いと、ローカル開発と公開の違いを説明できる。
